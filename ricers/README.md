# Ricers

Track who is doing what. One file per person.

To add your entry, create a file named `<your-name>.md` in this folder with your setup details.

## Template

```markdown
# Your Name

- **Laptop:** Model name
- **Distro:** e.g., Arch, Fedora, Ubuntu
- **Window Manager / DE:** e.g., Hyprland, i3, KDE
- **What I'm demoing:** What will people see on your machine at the stall
```
