Why You Should Install Linux

Apart from being very fun to play with the terminals, these things are the workhorses of the programmers world.
Most of the highest production quilty code comes from developers working out of this terminal.
Clients or Consumers interact with technology thorugh a GUI. What they dont realise is that this is actually limiting their abilities.

One of the biggest pros is speed and convenience. On windows most things require multiple clicks on a browser to get installed. Here they happen with one command. And that command can be run by any code. Meaning virutally a script can do almost anything you can, faster, better and automatically.
Learning Linux is crucial if you want a career as a server admin or someone who works the backend. 90% of the worlds servers run linux.
